# DMS Emoji Shortcodes

Type `:shortcode:` (like `:skull:`, `:blush:`, or `:v:`) in the DMS Spotlight launcher to copy or paste emojis.

## One-Line Install

```bash
curl -fsSL https://raw.githubusercontent.com/Frqme21/DMS-emojis/main/install.sh | bash
```

Then open **DMS Settings → Plugins**, click **Scan for Plugins**, and enable **Emoji Shortcodes**.
